Overview

Full custom CMOS design flow for the Boolean function F = AB + BC, implementing schematic capture, physical layout, DRC/LVS verification, and post-layout performance analysis using Cadence Virtuoso and Calibre.

The design targets the GlobalFoundries PDK, with transistor sizing following a 2:1 PMOS:NMOS ratio to balance rise/fall times. Total layout area: 12.748 µm².

Function Analysis & Optimization

Boolean Simplification

K-map analysis reduced the transistor count by factoring the function:

F = AB + BC = B(A + C)

This form enables direct complementary CMOS implementation with 8 transistors total (including the output inverter).

Network Design

Pull-Up Network (PUN):
  • 1 pMOS (B) in parallel with
  • 2 series pMOS (A and C)
  • Total: 3 pMOS transistors
Pull-Down Network (PDN):
  • 1 nMOS (B) in series with
  • 2 parallel nMOS (A and C)
  • Total: 3 nMOS transistors

Transistor Sizing

2:1 PMOS:NMOS ratio compensates for lower hole mobility, targeting balanced rise/fall times.

Layout Design

Strategy

  • pMOS transistors arranged for maximum diffusion sharing between adjacent devices
  • nMOS transistors placed to optimize diffusion continuity
  • Vias for cross-layer connections (C's drain to A's drain)
  • Metal1: horizontal tracks for VDD (top) and GND (bottom)
  • Polysilicon: vertical gate connections, minimal bends

Verification

DRC — Design Rule Check

Verified against foundry rules with Calibre DRC. Resolved:

  • Metal1 track misalignment
  • Minimum spacing violations

LVS — Layout vs. Schematic

Netlists match via Calibre LVS. Resolved:

  • Label settings configuration
  • Missing connection (via for cross-layer routing)

Analysis

Post-layout delays increase due to parasitic junction capacitances, metal resistance, contact/via resistance, and gate-to-diffusion coupling. The 30× load increase (0.5 → 15 fF) produced ~8× longer delays, consistent with the RC time constant relationship.

Tools

  • Cadence Virtuoso — Schematic Editor, Layout Suite XL, ADE Explorer
  • Calibre — DRC, LVS, xRC (Parasitic Extraction)
  • Process — GlobalFoundries PDK

Takeaways

  • Boolean simplification before layout reduces transistor count and area
  • Post-layout verification is essential — parasitics significantly impact timing
  • Source/drain sharing and interconnect optimization are critical for compact layouts
  • Iterative DRC/LVS debugging is standard in physical design flows
  • 2:1 PMOS:NMOS sizing effectively balances rise/fall times
